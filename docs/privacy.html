🔒 Privacy Policy

Last updated: October 2026

1. Overview

Raj FB Pro ("we", "our") is an internal operational tool used to automate media publishing from authorized cloud storage to Facebook Pages administered by the verified owner.

2. Data Collection & Processing

Our automation engine interacts exclusively with official Meta Graph APIs to:

  • Upload video and reel media files to designated Facebook Pages.
  • Retrieve basic operational metrics (follower count, view counts) for performance monitoring.

We do not collect, sell, or transfer any personal user data from page visitors, comments, or followers.

3. Authentication & Security

All Meta access tokens and Google Cloud Service Account credentials are kept strictly private in encrypted repositories or protected server environments. No credentials are exposed to public endpoints.

4. Data Deletion

For instructions on how to request data deletion, please see our Data Deletion Policy.

5. Contact

If you have any questions about this privacy statement, please contact the administrator via the official project repository.
