# Permanent Rule: 1:1 Google Drive Filename As Facebook Reel/Video Caption

## Rule Overview
Whenever videos are uploaded to any Facebook Page (Reels or Classic Videos), the title and description **MUST BE 100% PRESERVED FROM THE GOOGLE DRIVE FILENAME**.

## Strict Requirements
1. **Never Replace With Page Name:** Do NOT replace or prefix/suffix the caption with `#{page.name}` or generic tags.
2. **Preserve Emojis & Hashtags:** Google Drive filenames often contain viral emojis and hashtags (e.g. `Incredibles 2 💪🙏😂#friendship #pacman #trending #stickman.mp4`). These must be retained exactly as written by the user.
3. **Clean Container Extension Only:** Strip only known container file extensions (`.mp4`, `.mov`, `.mkv`, etc.) so that raw format extensions do not display in the viewer's caption.
4. **Applies to All Pages & Channels:** This rule is global and permanent across all current and future Facebook pages.
